# Michael Clark

Software engineer, dad, trail wanderer, sauna-goer.

**Professional Summary:** Software engineer with 18 years of experience shipping software systems. I've spent most of that time designing and building event-driven data infrastructure, internal developer platforms, and AI-powered data features, mostly on Kotlin/Java and Spring Boot. I also spent a few years on health information systems with .NET/C# and Angular. These days I lead a small team building AI-powered backend services for a business data platform.
